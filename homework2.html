02Model

2-2-1 结构与 9 个参数

2 个输入 → 2 个 sigmoid 隐藏单元 → 1 个输出。全部参数就是 4 个权重、2 个隐藏偏置、2 个输出权重、1 个输出偏置。

前向计算

hj = σ( x₁·W₁ⱼ + x₂·W₂ⱼ + bj )　j = 1,2
z = h₁·v₁ + h₂·v₂ + bo
ŷ = σ(z) = 1 / (1 + e−z)

σ 是 sigmoid，把任意实数压到 (0,1)。输出层把它当概率，0.5 为分类阈值。

# 课件 66/171 页原文，2-2-1 MLP 训练 XOR
import torch
import torch.nn.functional as F
torch.set_default_dtype(torch.float64)

x = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
target = torch.tensor([[0.],[1.],[1.],[0.]])

W = torch.nn.Parameter(torch.tensor([[2.,-2.],[-2.,2.]]))
b_hidden = torch.nn.Parameter(torch.tensor([-1.,-1.]))
v = torch.nn.Parameter(torch.tensor([[3.],[3.]]))
b_output = torch.nn.Parameter(torch.tensor([-2.5]))
parameters = [W, b_hidden, v, b_output]
optimizer = torch.optim.Adam(parameters, lr=0.03)

for epoch in range(1, 301):
    optimizer.zero_grad(set_to_none=True)
    hidden = torch.sigmoid(x @ W + b_hidden)
    logits = hidden @ v + b_output
    loss = F.binary_cross_entropy_with_logits(logits, target)
    loss.backward()
    optimizer.step()
我的实现：纯 Python，手写反向传播 
# 全批量 BCE-with-logits 的损失与梯度
def batch_loss_and_grad(p):
    grad = {...}; loss = 0.0
    for x, y in zip(X, Y):
        h, z, prob = forward(p, x)

        # ③ 损失：softplus(z) - y*z 等价于 BCE(logits)
        loss += max(z, 0.0) + math.log1p(math.exp(-abs(z))) - y * z

        # ④ 反向传播：BCE + sigmoid 的经典结果 dL/dz = σ(z) - y
        dz = (prob - y) / N

        for j in range(2):
            grad["v"][j] += h[j] * dz          # 输出层权重
        grad["bo"] += dz

        for j in range(2):
            dh   = dz * p["v"][j]                # 传回隐藏层
            dpre = dh * h[j] * (1.0 - h[j])      # sigmoid 导数 h(1-h)
            grad["W"][0][j] += x[0] * dpre
            grad["W"][1][j] += x[1] * dpre
            grad["bh"][j]   += dpre

    return loss / N, grad

两点实现细节

顺手记下的坑

① 损失写法　直接算 -log(σ(z)) 在 z 很负时会溢出成 log(0)。用 softplus(z) − y·z 展开，即 max(z,0) + log1p(exp(−|z|))，数值稳定，和框架里的 with_logits 是同一个东西。

② Adam 的偏差修正　前几步 m、v 都从 0 起步，直接除会严重偏小。必须除以 1−β₁ᵗ 和 1−β₂ᵗ，否则第一步的更新量会小得离谱。

参数不是被"设置"成答案的，是被梯度的方向一步步推过去的。看懂那张决策边界怎么从一条直线弯成十字，比最终 100% 的准确率有意思得多。 — 做完这次作业最直接的感受
